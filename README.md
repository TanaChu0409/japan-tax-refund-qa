# 日本退稅新制｜互動 Q&A 安心指南

靜態繁體中文 Q&A 網站，介紹 2026 年日本退稅新制、購物 QR Code、機場 Kiosk、離境後退款與資安注意事項。

## GitHub Pages 部署

1. 在 GitHub 建立 **Public** repository，建議命名 `japan-tax-refund-qa`。
2. 將本資料夾的 `index.html`、`.nojekyll`、`README.md` 上傳到預設分支 `main` 的根目錄。
3. 到 **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**。
4. 選擇 **Branch: main**、**Folder: / (root)**，按 **Save**。
5. 等待 GitHub Pages 完成發佈，網站會顯示於 `https://<YOUR_USERNAME>.github.io/japan-tax-refund-qa/`。

## 技術與隱私

- 單檔 HTML，含內嵌 CSS 和 JavaScript，不需要建置程序或後端。
- 問答透過本機關鍵字比對運作，不會把問題傳送至 AI API。
- 請勿在本網站輸入信用卡號、CVV、護照號碼等機敏資料。
- 資訊整理截至 2026-11-03，退稅規則或各業者流程仍可能更新；使用前以官方公告為準。
