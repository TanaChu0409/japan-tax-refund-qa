先記住這三件事

避免混淆不同 QR Code 和機場設備。

01

購物時：先付含稅價

在符合資格的店家購物，出示護照或店家接受的 VJW 免稅碼；確認店家完成免稅購買紀錄。

02

登記：收據 QR Code

某些店家提供退款 QR Code，掃描後到合作平台選擇退款方式。並非所有 QR Code 都相同。

03

出境：Kiosk 掃護照

託運前完成日本海關確認；綠燈通常通過，紅燈須依指示配合人工查驗。

信用卡與 Wi-Fi 資安指南

退稅不是付款驗證；遇到不合理的敏感資料要求應停止操作。

✅ 相對安全的做法

  • 優先使用機場實體 Kiosk 辦理海關確認。
  • 退款資訊在店內或自己的行動網路登記。
  • 手動核對退稅平台官方網域、HTTPS 與憑證。
  • 開啟信用卡即時通知、留存申請編號。
  • 先查平台手續費、退款期限及官方客服。

⚠️ 需要提高警覺

  • 不明 QR Code 導向陌生或拼錯字的網域。
  • 網站要求信用卡 CVV、交易 OTP，卻未解釋用途。
  • 遇到 HTTPS 憑證錯誤仍要求繼續。
  • 陌生人提供「機場專屬退稅連結」。
  • 尚未完成海關確認就以為退款確定成功。
機場官方流程需要輸入信用卡嗎？Tax Refund Kiosk 是護照與海關確認用途，並非信用卡退款登記機。Visit Japan Web 線上海關確認通常需要登入與旅客資料，但不應因「海關確認」而被要求輸入信用卡 CVV 或信用卡交易 OTP。公共 Wi-Fi 的安全性取決於網路與網站，請確認官方網址。
關於 GMO 資安事件：該如何解讀？

2026 年 10–11 月 GMO 集團部分服務有資安事故報導。這不等於所有 GMO 旗下系統、或所有日本退稅平台均被駭。要評估實際風險，必須確認你的收據 QR Code 指向哪家業者、該服務是否有官方受影響公告，以及實際蒐集哪些付款資料。

不要因為使用同一集團名稱，就直接推定支付資料已外洩；也不要因未有公開事故就認定零風險。
